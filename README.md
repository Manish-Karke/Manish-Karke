I’m a software engineer focused on building **mobile and backend systems with TypeScript**.

I have hands-on experience working on a production **POS system**, where I worked primarily with **React Native, Expo, GraphQL, Apollo Client, and WatermelonDB**.

A major area of my work has been designing **offline-first data flows**, local database models, synchronization with the backend, and keeping business logic separated from the UI using a clean architecture approach.

##  Production Experience

###  POS System — Dibtech

Worked on a production POS platform serving **retail, hospitality, and restaurant workflows**.

**My main areas of work included:**

*  React Native / Expo application development
*  GraphQL API integration using Apollo Client
*  Designing WatermelonDB models and schemas
*  Offline-first data synchronization
*  Applying clean architecture principles
*  Authentication and session handling
*  Product and category workflows
*  Building reusable and maintainable application components

A particularly important part of my work has been understanding how a POS application can continue operating with limited connectivity and synchronize local changes with the central backend when connectivity is restored.
